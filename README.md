# kbs-tech1220-a2

A smart appointment-booking chatbot that helps users schedule, reschedule, and manage bookings easily.

## Project overview

This project now includes a complete `index.html` page for the Chatbox - Bookings interface, with:

- A responsive booking dashboard UI
- A student team panel
- A Jotform AI agent embed
- A live booking counter persisted with `localStorage`
- Cross-tab count sync via the `storage` event
- Counter auto-increment when trusted Jotform `postMessage` booking events are detected

## How to run

1. Open `./index.html` in your browser.
2. Interact with the embedded chat widget.
3. Booking count updates are stored in browser `localStorage` under `chatbox_booking_count`.
